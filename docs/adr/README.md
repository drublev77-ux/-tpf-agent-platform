# Журнал архитектурных решений (ADR)

Здесь записаны решения о том, как устроена TPF Agent Platform: архитектура, логика заказа, работа агентов, платежи, инфраструктура. Автор и владелец платформы — Dy (Denny EL). Журнал показывает, какие творческие решения принимал человек, а какую работу выполняли агенты.

## Правила

1. **Решения принимает и подтверждает только владелец.** Агенты (подпись в Git «TPF Agent») могут подготовить черновик записи, но статус «Принято владельцем» ставит только Dy своим коммитом.
2. **Одна запись — одно решение.** Новая запись — отдельный файл `NNNN-kratkoe-nazvanie.md` по шаблону ниже, номер следующий по порядку.
3. **Ничего не переписывать задним числом.** Если решение изменилось, создаётся новая запись со статусом «Заменяет NNNN», а старая получает статус «Заменено NNNN».
4. **Писать честно.** Причину решения указывает владелец. Если причина неизвестна, поле остаётся с пометкой «ЗАПОЛНИТЬ ВЛАДЕЛЬЦУ», а не придумывается.
5. **Ссылки на доказательства.** В каждой записи — коммиты Git, в которых решение реализовано.
